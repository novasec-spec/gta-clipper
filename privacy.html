Privacy Policy

Munga Clipper · Last updated 19 November 2026

Summary

Munga Clipper is a personal tool used only by its developer to post their own clips to their own TikTok account. It does not collect, sell or share data about anyone else.

What data it uses

  • TikTok access tokens for the developer's own account, issued by TikTok after the developer authorises the app.
  • Basic account info (display name and open ID, via the user.info.basic scope) to confirm which account is connected.
  • The developer's own video files and captions, which are uploaded to TikTok when a post is made.

Where it is stored

Tokens and files stay on the developer's own computer. Nothing is stored on any server run by Munga Clipper, because there is none. Data is sent only to TikTok, and only to publish the developer's posts.

What it does not do

  • It does not access other TikTok users' accounts or data.
  • It does not use analytics, ads or tracking.
  • It does not sell or share data with third parties.

Removing access

Access can be revoked at any time in the TikTok app under Settings → Security → Manage app permissions. Deleting the local token file also removes the app's access.

Changes

This policy may be updated. The date at the top shows the latest version.
